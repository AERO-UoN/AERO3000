# AERO3000 — Flight Dynamics: Tutorial Code

Teaching MATLAB scripts for the AERO3000 Flight Dynamics course.

## Course Progression

| Week | Folder | File(s) | Topics |
|------|--------|---------|--------|
| 1 | `Week 1/` | `tut1_1.m`, `tut1_2.m`, `tut1_3.m` | MATLAB basics, functions, velocity computation, altitude profiles |
| 2 | `Week 2/` | `tut2_1.m`, `tut2_2.m` | Coordinate frames, 3-2-1 rotation matrices, Euler angles, quaternions |
| 3 | `Week 3/` | `tut3_1.m`, `tut3_2.m` | Curve fitting, lateral force equilibrium, roll angle from sideslip |
| 4 | `Week 4/` | `tut4.m` | Longitudinal static stability, neutral point, static margin |
| 5 | `Week 5/` | `load_stol_data.m`, `tut5.m` | Lateral-directional equilibrium, control authority, damaged aircraft analysis |
| 6 | `Week 6-7/` | `EOM_Example.m` | Introduction to Newton's equations of motion (1-DOF analytical solution) |
| 7 | `Week 6-7/` | `tut6_7.m`, `tut7.m` | Attitude kinematics: Euler angle and quaternion integration; RK4 numerical integration |
| 8–11 | `Week8-11/` | `tut8_11.m` | Longitudinal dynamic stability: state-space, eigenvalue analysis, short-period and phugoid approximations |

## Reference Textbooks

- Nelson, R. C. (1998). *Flight Stability and Automatic Control* (2nd ed.). McGraw-Hill.
- Stevens, B. L., Lewis, F. L., & Johnson, E. N. (2016). *Aircraft Control and Simulation* (3rd ed.). Wiley.
- Stengel, R. F. (2004). *Flight Dynamics*. Princeton University Press.

## Requirements

- MATLAB R2018b or later (no additional toolboxes required)

## Usage

Open each weekly folder and run the tutorial scripts in order. Each script is self-contained.
